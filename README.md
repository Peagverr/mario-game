# Окно: 3D-игра, которой управляют через веб-камеру

Кейс **Motion** (Admit Hackathon 2026), направление **A / Игра**. Команда **null pointers**.

Экран ноутбука становится **окном в маленький парящий 3D-мир**. Двигаешь головой, и картинка меняется, как в настоящем окне: можно заглянуть сбоку или сверху. Героем управляешь руками. Клавиатура и мышь не нужны.

## Играть

**Ссылка: https://peagverr.github.io/mario-game/**

Нужно: Chrome или Edge, веб-камера, хороший свет на лице и руках. Сядь напротив камеры примерно на расстоянии вытянутой руки и нажми «Включить камеру и играть». Это единственный клик, дальше все управляется жестами. Видео с камеры обрабатывается прямо в браузере и никуда не отправляется.

## Как играть

| Жест | Что делает |
|---|---|
| **Правая ладонь** справа от лица | Появляется круг-джойстик (он виден в окне камеры слева внизу). Ладонь в центре круга: герой стоит |
| **Сдвинуть ладонь** из центра круга | Идти: вверх, вперед; вниз, назад; в стороны, вбок |
| **Вернуть ладонь** в круг или опустить руку | Стоп |
| **Кулак** правой рукой | Прыжок. Держишь кулак: герой прыгает снова |
| **Щипок левой** (большой + указательный) и вести руку | Мир крутится и наклоняется, как будто держишь его рукой. Руку к камере или от нее: приблизить или отдалить |
| **Двигать головой** | Эффект окна: заглянуть в мир сбоку, сверху, за стену |
| **Две раскрытые ладони**, подержать секунду | Меню: продолжить, заново, в лобби, размер круга |
| Навести палец на кнопку и подержать секунду | Нажать кнопку в меню |

В начале игры короткое обучение (6 шагов): каждый жест нужно один раз сделать, и игра его засчитает. Обучение можно пропустить.

Чтобы было удобно:
- шагом с обрыва не упасть, через пропасть только прыжком. К мосту герой сам подстраивается, даже если идешь не точно по центру;
- после падения герой стоит, пока ты не поменяешь положение руки;
- круг-джойстик двигается вместе с лицом: сел по-другому, и круг снова рядом.

## Уровни

1. **Лобби.** Остров с порталами на уровни. Здесь же обучение.
2. **Острова.** Ходьба, прыжки, движущаяся платформа.
3. **Загляни.** Тайные звезды спрятаны во двориках за высокими стенами. Подними голову, и эффект окна позволит заглянуть через стену. Звезда засчитывается, как только ты ее **увидел**. Когда найдены все, открываются ворота к финишу.
4. **Поверни мир.** Мосты собраны из досок, разбросанных в воздухе. Поверни мир щипком левой рукой: доски съедутся, и под нужным углом мост станет твердым.

В конце уровня: очки, время, точность жестов, разбор ошибок, таблица рекордов.

## Режим «ошибка»

Игра замечает жесты, которые сделаны **почти правильно**, и говорит, что именно исправить. На экране одна подсказка за раз, она подсвечивает проблемные пальцы красным на скелете в окне камеры. Короткие переходы между жестами подсказок не вызывают, а ушедшая подсказка не возвращается 8 секунд.

| Что заметили | Подсказка (пример) |
|---|---|
| Кулак сжат не до конца | «Сожми кулак полностью, не согнуты: безымянный, мизинец» (эти пальцы подсвечиваются) |
| Ладонь не заходит в круг | «Заведи правую ладонь в желтый круг, он в окне камеры слева внизу» |
| Левая рука повернута ребром | «Боком камера руку не видит, поверни ладонь к камере» |
| Рука у края кадра | «Правая рука уходит за левый край кадра, сдвинь ее правее» |
| Не та рука | «Ходьба правой рукой. Левой делай щипок» |
| Слишком близко или далеко | «Отодвинься примерно на 15 см» (считаем по расстоянию между зрачками) |
| Голова повернута | «Повернись лицом к экрану» |
| Темно | «Включи свет или повернись лицом к окну» |
| Камера закрыта | «Камера показывает черный кадр, открой шторку камеры» |

Где в коде: `src/input/errors.ts` (правила и фильтр подсказок), тесты в `src/input/errors.test.ts`.

## Запустить у себя

```bash
npm install
npm run dev
```

Открыть http://localhost:5173 в Chrome. Тесты: `npm test`. Выложить новую версию на сайт: `npm run deploy`.

## Как устроено (коротко)

- **Распознавание:** MediaPipe (Google) дает точки рук и лица. Все остальное наше: жесты по объемным точкам руки (`src/input/gestures.ts`), круг-джойстик от лица (`palmJoystick.ts`), щипок (`worldGrab.ts`), положение головы по зрачкам (`head.ts`), фильтр дрожания One Euro (`oneEuro.ts`).
- **Эффект окна:** асимметричная перспектива по положению головы (`src/game/WindowCamera.tsx`).
- **Игра:** Three.js, React Three Fiber, физика Rapier. Правила ходьбы и мягких краев с тестами: `src/game/walk.ts`.
- **Разделение:** распознавание пишет в один общий объект `src/shared/controlState.ts`, игра только читает его.

Использовано: MediaPipe Tasks Vision (Apache-2.0), Three.js, React Three Fiber, drei, Rapier, postprocessing (MIT), React, Zustand, Vite, TypeScript, шрифты Unbounded и Onest (OFL). 3D-моделей нет: мир собран из простых фигур, звуки синтезируются в браузере.
