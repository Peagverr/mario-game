# Окно — 3D-игра, которой управляют через веб-камеру

Кейс **Motion** (Admit Hackathon 2026), направление **A / Игра**.

Экран ноутбука становится **окном в парящий 3D-мир**. Камера следит за головой, и перспектива меняется так, будто монитор — настоящее окно (эффект *head-coupled perspective*). Героем управляешь руками: без клавиатуры и мыши.

## Как запустить

**Онлайн:** ссылка на деплой _(будет добавлена)_. Нужен Chrome или Edge, веб-камера и разрешение на доступ к ней.

**Локально:**

```bash
npm install
npm run dev
```

Открыть http://localhost:5173 и нажать «Включить камеру и играть». Камера в браузере работает только на `localhost` или по `https`.

## Управление

Схему ходьбы выбрали по исследованиям жестовой навигации: указание пальцем предпочли 25 из 30 участников в сидячем положении, и нагрузка у него ниже других жестов ([Frontiers in VR, 2023](https://www.frontiersin.org/journals/virtual-reality/articles/10.3389/frvir.2023.1169654/full)). Главное в схеме — «идти» и «стоять» делаются **разными жестами**, а не расстоянием от невидимого центра.

| Движение | Действие |
|---|---|
| **Указательный палец** правой руки, остальные согнуты | Идти туда, куда показываешь: вверх — вперёд, в сторону — вбок |
| **Раскрытая ладонь** или опущенная рука | Стоп |
| **Кулак** правой | Прыжок в ту сторону, куда показывал палец. Держишь — прыжок выше и повторяется |
| **Щипок левой** (большой + указательный) и вести руку | Влево-вправо — повернуть мир, вверх-вниз — наклонить, к камере — приблизить |
| **Двигать головой** | Эффект окна: заглянуть в мир сбоку, сверху, за стену |
| **Две раскрытые ладони** ~1 секунду | Меню: продолжить, заново, в лобби, схема ходьбы |
| Навести палец на кнопку и держать 1 секунду | Нажать кнопку в меню |

Удобство, которое мы добавили:
- после падения герой стоит, пока рука «там же» — идти он начнёт, только когда жест изменится (идея из тестов);
- **мягкие края**: шагом с обрыва не упасть, через пропасть — только прыжком;
- в меню можно переключиться на старую схему «ладонь-джойстик» и сравнить.

Единственный клик за игру — «Включить камеру»: браузер требует его для доступа к камере и звуку.

## Уровни

Каждый уровень учит своей «фишке» — без неё его не пройти.

1. **Лобби** — остров с порталами. Здесь же проходит обучение.
2. **Острова** — палец, стоп, прыжки, движущаяся платформа.
3. **Загляни** — тайные звёзды спрятаны в двориках за высокими стенами. С обычного ракурса их не видно: **подними голову**, и эффект окна позволит заглянуть через стену. Звезда засчитывается, как только её **увидели**: игра проверяет, что луч от камеры до звезды ничем не перекрыт. Ворота к финишу откроются, когда найдены все.
4. **Поверни мир** — мосты-призраки из досок, рассыпанных в воздухе. **Поворачиваешь мир щипком** — доски съезжаются, под нужным углом мост собирается и становится твёрдым.

Итоги уровня: очки, время, точность жестов, разбор ошибок, таблица рекордов (своя для каждого уровня), кнопка «Дальше».

## Режим «ошибка» (твист)

Файл [`src/input/errors.ts`](src/input/errors.ts). Работает в два шага:

1. **Правила на каждый кадр** (`detectCandidates`) ищут *почти правильные* движения. Пороги считаются относительно размера ладони и по объёмным точкам руки, поэтому работают на любом расстоянии и при любом повороте кисти.
2. **Фильтр** (`HintFilter`) показывает подсказку, только если проблема держится дольше порога (0,35–1,2 с). Обычные переходы между жестами (~0,2 с) подсказок не вызывают, и подсказки не мигают.

| Что замечаем | Как | Подсказка (пример) |
|---|---|---|
| Показываешь пальцем, но выпрямлены и другие | Кроме указательного выпрямлены 2–3 пальца | «Чтобы идти, оставь выпрямленным только указательный — согни средний, безымянный» (эти пальцы подсвечиваются красным) |
| Указательный наполовину | Остальные согнуты, указательный — нет | «Выпрями его — идти, согни полностью — прыжок» |
| Палец смотрит в камеру | Палец на картинке короткий | «Наклони его туда, куда идти» |
| Неполный кулак | Согнуты 2–3 пальца из 4 | «Сожми кулак полностью — не согнуты: безымянный, мизинец» |
| Неплотный щипок | Пальцы сблизились, но не сомкнулись | «Сведи большой и указательный плотнее — осталось примерно 12 мм» |
| Рука ребром к камере | Левая рука пропала посреди щипка | «Боком камера руку не видит — поверни ладонь к камере» |
| Рука у края кадра | Точки руки у границы изображения | «Правая рука уходит за левый край кадра — сдвинь её правее» |
| Не та рука | Видна только левая раскрытая ладонь | «Ходьба — правой рукой. Левой делай щипок» |
| Слишком близко или далеко | Расстояние по зрачкам (~63 мм между ними) | «Отодвинься примерно на 15 см» |
| Голова повёрнута | Угол из матрицы поворота лица | «Повернись лицом к экрану» |
| Темно | Средняя яркость кадра | «Включи свет или повернись лицом к окну» |
| Нет лица или рук | Нет распознавания дольше секунды | «Подними правую руку и покажи пальцем, куда идти» |

Каждая подсказка показывается текстом со стрелкой, подсвечивает проблемные точки на скелете в мини-окне камеры, звучит сигналом и озвучивается голосом (если в системе есть русский голос). В конце уровня — **разбор ошибок** с советами и **точность жестов**.

## Собственная логика распознавания

MediaPipe выдаёт только точки руки и лица. Всё остальное написано нами:

- `src/input/gestures.ts` — три состояния каждого пальца по объёмным точкам (worldLandmarks), кулак, ладонь, указание с направлением, щипок с гистерезисом (включается и выключается на разных порогах, чтобы не мигал);
- `src/input/oneEuro.ts` — фильтр One Euro против дрожания точек;
- `src/input/head.ts` — положение головы в метрах относительно экрана по расстоянию между зрачками;
- `src/input/tracker.ts` — ходьба пальцем с «запоминанием» направления для прыжка, прыжок по «фронту» кулака, поворот, наклон и зум мира щипком, меню двумя ладонями, курсор для меню;
- `src/game/WindowCamera.tsx` — асимметричная перспектива для эффекта окна; экран «проходит» через героя, поэтому герой всегда в центре;
- `src/game/Player.tsx` — мягкие края, блокировка после падения, прыжок с буфером и «временем койота».

## Устройство проекта

```
src/
  shared/controlState.ts  ← КОНТРАКТ: распознавание пишет, игра читает
  shared/gameStore.ts     ← сцена, фаза игры, счёт, статистика
  input/                  ← камера, MediaPipe, жесты, режим ошибки
  game/                   ← 3D: камера-окно, герой, окружение
    scenes/index.ts       ← реестр уровней: новый уровень = папка + строка
    scenes/lobby|level1|level2|level3/
  ui/                     ← экраны, обучение, подсказки, итоги, рекорды
```

Игра не знает о MediaPipe: она читает только `control` из `controlState.ts`.

**Режим разработки:** в `npm run dev` на стартовом экране есть кнопка «без камеры — клавиатура»: WASD — ходьба, пробел — прыжок, Q/E — поворот мира, Z/X — зум, стрелки — «голова». В собранной версии клавиатура отключена. Адрес с `?debug` показывает под окном камеры замеры щипка, пальцев и головы.

- [MediaPipe Tasks Vision](https://ai.google.dev/edge/mediapipe/solutions/vision/gesture_recognizer) (Google, Apache-2.0): Gesture Recognizer и Face Landmarker; модели загружаются с серверов Google.
- [Three.js](https://threejs.org), [React Three Fiber](https://r3f.docs.pmnd.rs), [drei](https://github.com/pmndrs/drei), [Rapier](https://rapier.rs) (физика), [postprocessing](https://github.com/pmndrs/postprocessing) — MIT.
- React, Zustand, Vite, TypeScript.
- Шрифты Unbounded и Onest (Google Fonts, OFL).
- 3D-моделей пока нет: мир собран из простых фигур. Звуки синтезируются в браузере.
