# Окно

3D-игра в браузере, которой управляют через веб-камеру. Без клавиатуры и мыши.

Команда **null pointers**, Admit Hackathon 2026, кейс Motion, направление «Игра».

**Играть: https://mariogame-gilt.vercel.app**

Нужны Chrome или Edge, веб-камера и свет на лице. Сядь напротив камеры и нажми «Включить камеру и играть». Видео с камеры никуда не отправляется, все считается в браузере.

## Как играть

| Жест | Что делает |
|---|---|
| Правая ладонь справа от лица | Появляется круг-джойстик. Ладонь в круге: герой стоит |
| Сдвинуть ладонь из круга | Герой идет в ту сторону |
| Кулак правой рукой | Прыжок |
| Щипок левой рукой и вести руку | Повернуть и наклонить мир. К камере или от нее: приблизить или отдалить |
| Двигать головой | Экран как окно: можно заглянуть сбоку или сверху |
| Две раскрытые ладони | Меню |

В начале короткое обучение, его можно пропустить.

## Уровни

1. **Лобби:** порталы на уровни и обучение.
2. **Острова:** ходьба и прыжки.
3. **Загляни:** звезды спрятаны за стенами, подними голову, чтобы их увидеть.
4. **Поверни мир:** поверни мир щипком, и мост соберется из досок.

## Подсказки

Если жест сделан почти правильно, игра говорит, что исправить. Например: «Сожми кулак полностью, не согнуты: безымянный, мизинец». Нужные пальцы подсвечиваются в окне камеры.

## Запустить у себя

```bash
npm install
npm run dev
```

Открыть http://localhost:5173 в Chrome.

Сделано на MediaPipe, Three.js и React. Весь код написан после старта хакатона.
