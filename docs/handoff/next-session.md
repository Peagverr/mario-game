## Аудит: что не так и почему

1. **«Ночь и день — полная фигня» (отзыв 3.10).** Причина: поменялись только свет и небо, а сам мир остался мультяшным — яркая трава, деревья-конусы, гладкие кубы, обводки. На референсе атмосферу делают **предметы и материалы**: камень с фактурой и мхом, скалы под островами, руины и башни в дымке, лучи сквозь них. Вывод: дальше работать не со светом, а с миром — через Blender и настоящие ассеты.
2. **Облака перекрывают остров**, если сильно наклонить мир (почти горизонтальный взгляд): облака висят между камерой и островом. Перенести облака дальше/ниже или заменить слоями тумана.
3. **Тени** от ключевого света бывают длинными полосами. Сейчас для теней солнце «поднято» до 32°, перепроверить после новых материалов.
4. **Цвета атмосферы** подбирались под мультяшный мир — после новых материалов перенастроить таблицу `KEYS` в `src/game/atmosphere/atmosphere.ts`.
5. **Старый сайт на GitHub Pages** (https://peagverr.github.io/mario-game/) показывает версию от 30.09 — спросить, отключить ли.
6. **Реплики голоса под фичи, которых нет:** «Остров разрушается, беги к мосту», «Подними левую ладонь и веди в сторону» — это зона Абзала, не трогать без его слова.

## Правила работы (договорённости с командой)

- **Сначала план, потом код.** Каждый шаг — только после «делай». Объяснять простыми словами, без жаргона (пользователь — не разработчик).
- **Сразу в `main`** — пользователь решил выкладывать всё на сайт; если сломается — откат (см. выше).
- **Не трогать** (зона Абзала): `src/input/*`, `src/shared/*`, `src/ui/*`, `src/game/voice*`, `src/game/holo/*`, `scripts/*`, `public/voice/*`; в `spiritState.ts` только добавлять.
- **Нельзя менять:** коллайдеры и данные уровней (`src/game/scenes/*/levelData.ts`: верх платформы = `top`), стены двориков (тест `level2.test.ts`), механику `GhostBridge`. Эффект окна (`WindowCamera.tsx`) строит свою матрицу проекции — проверять всё с движением «головы».
- **Скорость:** цель 60 к/с на среднем ноутбуке; до ~150 вызовов отрисовки, ~300 тыс. треугольников, текстуры 1–2K, все ассеты до ~15 МБ; режим `runtime.lowQuality` должен быть заметно легче.
- **Лицензии:** только CC0 / CC BY / свои; авторов — в README.
- README и тексты для формы — без буквы «ё» и длинных тире. Комментарии в коде — по-русски, коротко.

## Как проверять без камеры

- `npm run dev` → `http://localhost:5173/?debug&step` → «[dev] без камеры — клавиатура». WASD — ходьба, пробел — прыжок, Q/E — поворот мира, стрелки — «голова».
- `?step`: кадры не крутятся сами, их двигает `window.__advance(кадров)`; доступны `window.__scene`, `window.__camera`, `window.__runtime`, `window.__game`, `window.__control`.
- Панель браузера Claude обычно **скрыта** — кадры там стоят. Скриншот делать **одной пачкой** сразу после `__advance` (`browser_batch`: javascript `__advance(3)` → screenshot), иначе ловится пустой холст.
- Уровень грузится не мгновенно (физика): перед проверкой ждать, пока в `__scene` станет больше ~100 объектов.
