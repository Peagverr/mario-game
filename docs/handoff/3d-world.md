## 1. Что это за игра — пойми душу, а не только код

«Окно» — 3D-платформер, которым управляют **без клавиатуры и мыши**, только телом перед обычной веб-камерой. Всё это идеи Абзала, и они главное в проекте:

- **Экран — это окно в мир.** Камера следит за головой игрока, и перспектива меняется, как в настоящем окне (head-coupled perspective, `src/game/WindowCamera.tsx`). Наклонился — заглянул за стену. Это наша главная инновация. **Поэтому глубина — твой главный инструмент:** передний план, средний и дальний, слои дымки, параллакс. Чем богаче глубина, тем сильнее вау от движения головы.
- **Правая ладонь у лица — джойстик.** Кулак — прыжок. **Движение руки поворачивает и наклоняет весь мир.** Две ладони — меню.
- **Голос «Окна»** — спокойный женский ИИ-голос в духе «центра управления полётами». Он ведёт игрока. Это **она**.
- **Дух — её тело в мире.** Маленький светящийся призрак, как на референсе. Летит рядом с героем, показывает дорогу и **показывает управление**: сам на секунду «берёт руль», и герой идёт или мир поворачивается, чтобы игрок увидел причину и следствие и повторил.
- **История через свет:** «Окно» просыпается в сумерках, а к финалу встаёт солнце.

Сцены и их зрелищный момент. Делай свет и атмосферу так, чтобы эти моменты **били по эмоциям**:

| Сцена | Время суток `t` | Момент, который должен впечатлить |
|---|---|---|
| Лобби (порталы, обучение) | ≈ 0.1, сумерки, синий час, первые звёзды | **Пробуждение:** темно, «Камера включена. Я тебя вижу», загорается дух, рассеивается туман, светятся порталы |
| «Острова» (ходьба, прыжки) | ≈ 0.35 | Прыжки над бездной: далёкие руины в дымке, светлячки, ощущение высоты |
| «Загляни» (голова заглядывает за стену) | ≈ 0.6, золотой час | Дворик за стеной открывается поднятием головы, внутри тёплое свечение тайной звезды |
| «Поверни мир» (мост собирается при повороте) | ≈ 0.85 | Сборка моста — зрелище: доски слетаются, свет, искры |
| Итоги и финал | = 1, рассвет | Солнце встаёт, тепло, «Окно открыто» — как нижний правый кадр референса |

Описание сцен — в `src/game/scenes/`, порядок — в `src/game/scenes/index.ts`.

## 2. Как запустить

```bash
git clone https://github.com/Peagverr/mario-game.git
cd mario-game
git checkout final
git checkout -b final-world
npm install
npm run dev
```

- **Без камеры:** открой `http://localhost:5173/?debug` и нажми «[dev] без камеры — клавиатура». Управление: WASD — ходьба, пробел — прыжок, Q/E — поворот мира, Z/X — зум, **стрелки — движение «головы» (эффект окна)**, P — пауза.
- **С камерой** — обычный запуск, просто по ссылке.
- **Стенд духа:** `http://localhost:5173/?spirit`.
- Проверки: `npm run typecheck`, `npm test`, `npm run build` — всё должно быть зелёным.
- Прочитай `README.md` целиком.

**Blender + MCP.** Blender установлен. Подключи [blender-mcp](https://github.com/ahujasid/blender-mcp):
```bash
claude mcp add blender uvx blender-mcp
uvx blender-mcp install-addon
```
Затем в Blender: Edit → Preferences → Add-ons → включить «Blender MCP». В окне 3D-вида нажать N → вкладка BlenderMCP → Start MCP Server. Через него: Poly Haven (текстуры и HDRI, CC0), Sketchfab, Poly Pizza, сборка сцен, перекраска, запекание AO, экспорт GLB.

## 3. Арт-цель

**Главный референс — `target-mood.png`.** Плюс настроение **Unravel Two**.

- **Свет:** низкое солнце у горизонта, тёплый золотой ключевой свет против холодных синих теней. Лучи сквозь руины. Корона солнца.
- **Воздух:** дальние скалы и руины тают в дымке. Слои глубины. Пылинки и светлячки. Влажность.
- **Материалы с фактурой:** старый камень, мох, корни, трава с вариациями. **PBR** (`meshStandardMaterial` / `meshPhysicalMaterial` + текстуры), а не плоский toon.
- **Мир:** руины и скалы над бездной. Каменные платформы, старые мосты и арки, фонари, корни, вдали силуэты башен. Таинственно, немного мрачно, но тепло и с надеждой.
- **Стиль:** **стилизованный реализм**, как в Unravel Two, Alba, Sky: Children of the Light. Не фотореализм и не мультик.

**Чего НЕ надо:** `too-bright-not-this.png`. Яркая «мультяшная» подача, как в Майнкрафте. Нынешний вид игры (яркий toon с чёрными обводками) — тоже от него уходим. Модели из ярких паков брать можно, но только с новыми материалами и светом.

**Время суток `t ∈ [0..1]`** — один параметр, все цвета и настройки в одном модуле (например, `src/game/atmosphere/`). Значения по сценам — в таблице выше. При смене сцены — плавный переход за несколько секунд.

**Свет и постобработка:**
- небо-шейдер с солнцем и короной, звёзды при малом `t`;
- лучи (`GodRays` из `@react-three/postprocessing` или дешевле);
- туман и дымка по `t`;
- цветокоррекция: тени в холодный синий, света в тёплый;
- Bloom только на солнце, звёздах, светлячках, духе, визоре героя и бликах.

## 4. Дух — сделай его 1:1 как на референсе

Это **твоя** зона по внешнему виду. На референсе:
- маленький призрак из света, большая круглая голова (около 55–60% роста), два больших светящихся овальных глаза;
- тело сужается в развевающийся хвост, маленькие ручки;
- полупрозрачный ледяной электрически-голубой, яркий контур (fresnel), внутреннее свечение;
- сыплет частицы с хвоста, в полёте оставляет световые ленты;
- характер — милая, любопытная, живая. **Она** — тело голоса «Окна», облик мягкий и нейтрально-милый, без мальчишеских черт.

Код сейчас в `src/game/spirit/`: первая версия от другого агента. **Внешний вид переделывай свободно:** `Spirit.tsx`, `spiritMaterials.ts`, геометрия, шейдеры, частицы. **Не меняй API** в `src/game/spirit/spiritState.ts`: `spiritAppear`, `spiritVanish`, `spiritGuide`, `spiritFollow`, `spiritCelebrate`, `spiritAlert`. На них Абзал вешает поведение (обучение, «дух показывает управлением»). Добавлять новые функции можно. Свечение должно «дышать» с голосом: `voiceLevel()` из `src/game/voice.ts` даёт громкость 0..1. Дух должен смотреться на любом `t`, особенно в сумерках.

## 5. Герой — мрачнее, в sci-fi

Модель: **[Cute Cartoon Robot](https://sketchfab.com/3d-models/cute-cartoon-robot-1515bb8be733456e980fea34e37dec39)** (Sketchfab, CC BY — указать автора в README). В оригинале он белый, глянцевый, с жёлтым визором — **игрушка**, и в нашем мире будет смотреться вклеенным. Переделай в Blender:
- **Материалы матовые, слегка потёртые,** меньше глянца. Корпус ближе к **красному малышу с референса**: красный — наш узнаваемый цвет.
- **Мягкий свет из визора и груди** — пусть светится в сумерках.
- Силуэт милый и читаемый на расстоянии.
- **Заменить `Hero()` в `src/game/Player.tsx`. Физику не трогать:** капсула `RADIUS = 0.35`, `HALF_HEIGHT = 0.35`, рост около 1.4 м. Модель вписать в эти размеры.
- **Анимации:** стоит, идёт, в прыжке, приземлился — по скорости и `grounded`. Сохрани то, что уже есть в `Player.tsx`: сжатие при приземлении, покачивание, поворот к направлению движения.

## 6. Жёсткие ограничения (нарушишь — сломаешь игру)

1. **Геометрия уровней — это данные:** `src/game/scenes/*/levelData.ts`. `top` — высота поверхности, `w/d/h` — размеры, по ним строятся коллайдеры. Визуал может обрамлять платформы как угодно (скалы, корни, мох по бокам и снизу), **но верх совпадает с `top`**, а края и пропасти должны **легко читаться**: это платформер. Коллайдеры не меняй.
2. **«Загляни»:** стены двориков проверяет тест `src/game/scenes/level2/level2.test.ts`, видимость звезды считается лучами по коллайдерам. Стены можно одеть в камень, размеры и коллайдеры — нет.
3. **«Поверни мир»:** мост-призрак в `Level3.tsx` (`GhostBridge`). Делай из него зрелище, но механику не меняй.
4. **Эффект окна:** `WindowCamera.tsx` каждый кадр строит свою асимметричную матрицу проекции (`NEAR = 0.5`). Небо, лучи, туман и экранные эффекты проверяй **с движением головы** (стрелки в dev-режиме). Ничего не должно ломаться и дёргаться.
5. **Не трогай** (это зона Абзала: управление, голос, обучение, музыка): `src/input/*`, `src/shared/*`, `src/ui/*`, `src/game/voice*`, `src/game/holo/*`, `spiritState.ts` (только добавлять), `scripts/*`, `public/voice/*`. Без правки там никак — сначала спроси Абзала.
6. **Производительность — критично.** Один финалист сделал шикарную 3D-игру, но она лагала, и он не попал в топ-10. Параллельно в браузере работает распознавание MediaPipe (руки и лицо, на GPU). Цель — **60 к/с на среднем ноутбуке со встроенной видеокартой**:
   - ориентир: до ~150 вызовов отрисовки и до ~300 тысяч треугольников в кадре;
   - текстуры до 1–2K;
   - GLB сжимать (gltf-transform: meshopt и webp), все ассеты в сумме до ~15 МБ;
   - уже есть `PerformanceMonitor` → `runtime.lowQuality`; для слабых машин нужен заметно более дешёвый режим.
7. **Лицензии:** только CC0 / CC BY / свои. Всё использованное — в README, раздел «Что использовано», с авторами.

## 7. Как работать (обязательно)

**Сначала думать, потом кодить.** Абзал не любит «тупых кодеров», которые сразу пишут код. Первая строчка кода появляется только после этапов 0.1–0.3.

**0.1. Глубокий ресерч в интернете.** Ищи и читай, а не вспоминай:
- **Как устроен свет и атмосфера** в Unravel Two, Alba, Sky: Children of the Light, Journey: разборы арта, доклады GDC, интервью художников. Что именно делает их кадр дорогим.
- **Как это делают в WebGL / three.js / React Three Fiber:**
  - небо с солнцем;
  - лучи (GodRays и дешёвые альтернативы);
  - объёмный туман и дымка, высотный туман;
  - стилизованные PBR-материалы, мох по нормали сверху, трава;
  - цветокоррекция (LUT);
  - частицы-светлячки;
  - светящийся персонаж (fresnel, ленты-шлейфы).
- Примеры с исходниками: three.js examples, pmndrs, Codrops, Shadertoy.
- **Производительность** постобработки и теней на встроенных видеокартах; что выключать в режиме низкого качества.
- **Ассеты CC0 / CC BY** под наш стиль: руины, скалы, мох, фонари, HDRI и текстуры Poly Haven. Изучи модель робота со Sketchfab: топология, материалы, есть ли риг.
- **Наш код:** README, `WindowCamera.tsx`, `GameCanvas.tsx`, `Environment.tsx`, `Player.tsx`, `src/game/spirit/`, данные уровней.

Записывай источники: они понадобятся в плане.

**0.2. Брейншторм.** Для атмосферы, героя и духа — по 2–3 разных подхода. Для каждого:
- как будет выглядеть;
- сколько стоит по производительности;
- риски;
- сколько времени займёт.

Выбери лучший и честно объясни почему.

**0.3. План и уточнения.** Напиши `docs/handoff/world-plan.md`:
- выводы ресерча со ссылками;
- выбранные подходы;
- порядок работ;
- бюджет производительности;
- **список вопросов к Абзалу** — всё, где вкус или решение за ним.

Покажи план Абзалу, получи ответы, и только потом пиши код.

**1. Стоп-кран: первый кадр-витрина.** Собери **одну** сцену: остров лобби в сумерках, новый герой, дух, свет, дымка, глубина. Сделай скриншот и **покажи Абзалу**. Масштабировать на всё остальное — только после его «да» на внешний вид. В прошлый раз целый прогон ушёл на визуал, который он не хотел: под одними словами понимали разное.
2. **Цикл арт-директора.** Каждое изменение — скриншот и честная критика: композиция, цвет, читаемость платформ, пересвет, грязные тени, полосы на градиентах, «похоже ли на референс». Потом исправление. Минимум 3 раунда на сцену.
3. **Играй, а не только смотри:** dev-режим с клавиатурой, пройти уровень, попрыгать, подвигать «головой». Красота, которая мешает играть, — провал.
4. **Коммить маленькими шагами** в `final-world`. В `main` и в деплой (`npm run deploy`) — только с разрешения Абзала.
5. Комментарии в коде **по-русски, коротко**, как в остальном проекте (пример — `src/game/WindowCamera.tsx`).

## 8. Порядок работы

0. Ресерч → брейншторм → `world-plan.md` с вопросами → ответы Абзала (раздел 7).
1. Модуль атмосферы (`t`, небо, солнце, свет, туман, лучи, цветокоррекция) + витрина лобби с героем и духом → **показать Абзалу**.
2. Доводка героя и духа в витрине → **показать**.
3. Одеть острова: скалы, мох, корни, руины, задние планы с силуэтами башен, слои глубины.
4. Все уровни, арка `t`, зрелищные моменты из таблицы в разделе 1, финал на рассвете.
5. Низкое качество, производительность, README с авторами.

**Готово, когда:** любой кадр игры можно поставить рядом с `target-mood.png` и он не проигрывает по настроению; платформы и пропасти читаются; дух живой; 60 к/с на среднем ноутбуке; typecheck, тесты и сборка зелёные; Абзал сказал «да».
