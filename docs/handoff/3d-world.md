## 1. Как запустить

```bash
git clone https://github.com/Peagverr/mario-game.git
cd mario-game
git checkout final
git checkout -b final-world
npm install
npm run dev
```

- Открыть http://localhost:5173.
- **Без камеры:** открой `http://localhost:5173/?debug` и нажми «[dev] без камеры — клавиатура». Управление: WASD — ходьба, пробел — прыжок, Q/E — поворот мира, Z/X — зум, стрелки — «движение головы» (эффект окна), P — пауза.
- Проверки: `npm run typecheck`, `npm test`, `npm run build` — все должны быть зелёными.
- Прочитай `README.md` целиком: там устройство проекта.

**Blender + MCP:** Blender установлен. Подключи [blender-mcp](https://github.com/ahujasid/blender-mcp):
```bash
claude mcp add blender uvx blender-mcp
uvx blender-mcp install-addon
```
Затем в Blender: Edit → Preferences → Add-ons → включить «Blender MCP». В окне 3D-вида нажать N → вкладка BlenderMCP → Start MCP Server. Через него можно брать ассеты из Poly Haven (текстуры и HDRI, CC0), Sketchfab и Poly Pizza, собирать сцены, перекрашивать, запекать AO и экспортировать GLB.

## 2. Что за игра (коротко)

«Окно» — 3D-платформер на парящих островах.
- **Экран — это окно в мир (head-coupled perspective):** камера следит за головой игрока, и перспектива меняется, как в настоящем окне. Это наша главная инновация. Глубина сцены, передний план и параллакс здесь решают всё.
- **Управление:** правая ладонь у лица — джойстик, кулак — прыжок, щипок левой — поворот и наклон мира, две ладони — меню.
- **Голос «Окна»:** спокойный женский ИИ-голос в стиле «центра управления полётами» ведёт игрока. Это **она**.
- **Компаньон — светящийся дух.** Её тело в мире: маленький призрак из света с большой головой и светящимися глазами, летит рядом с героем. Его делают в `src/game/spirit/`. Твоя задача по нему одна: чтобы он красиво светился в твоей атмосфере.
- **Сцены:** лобби (порталы) → «Острова» (ходьба и прыжки) → «Загляни» (заглянуть за стену головой) → «Поверни мир» (собрать мост поворотом мира).

## 3. Арт-цель — внимательно

**Главный референс:** `docs/handoff/reference/target-mood.png`. Открой и изучи. Плюс настроение **Unravel Two**.

Что из него берём:
- **Кинематографичный свет.** Низкое солнце у горизонта, тёплый золотой ключевой свет против холодных синих теней и дымки.
- **Глубина воздуха.** Дальние острова и скалы растворяются в дымке. Лучи света. Плавающие пылинки и светлячки.
- **Материалы с фактурой.** Камень, мох, корни, влажность, трава с вариациями цвета. **PBR (`meshStandardMaterial` / `meshPhysicalMaterial`), а не плоский toon.**
- **Мир — руины и скалы над бездной.** Каменные платформы, старые мосты, арки, фонари, корни. Немного мрачно и таинственно, но тепло.
- **Светящийся компаньон хорошо виден** на тёмном фоне.

**Чего НЕ надо:** `docs/handoff/reference/too-bright-not-this.png`. Яркая, насыщенная «мультяшная» подача «как в Майнкрафте». Нынешний вид игры (яркий toon с чёрными обводками) — тоже то, от чего уходим. Отдельные модели из таких паков брать можно, но только с новыми материалами и светом.

**Стиль:** стилизованный реализм. Не фотореализм и не мультик. Как в Unravel Two, Alba, Sky: Children of the Light.

**Арка «сумерки → рассвет» (сюжет через свет):** «Окно» просыпается в сумерках, к финалу встаёт солнце. Время суток — один параметр `t ∈ [0..1]`:
- лобби ≈ 0.1 — сумерки, синий час, первые звёзды;
- «Острова» ≈ 0.35;
- «Загляни» ≈ 0.6 — золотой час;
- «Поверни мир» ≈ 0.85;
- итоги и финал = 1 — рассвет, тепло.

При смене сцены — плавный переход за несколько секунд. Все цвета и параметры держи в одном модуле, например `src/game/atmosphere/`.

**Свет и постобработка:**
- небо-шейдер с солнцем и короной;
- лучи (`GodRays` из `@react-three/postprocessing` или дешевле);
- туман и дымка по `t`;
- цветокоррекция: тени в холодный синий, света в тёплый;
- Bloom только на солнце, звёздах, светлячках, духе и бликах.

## 4. Герой

Выбран **[Cute Cartoon Robot](https://sketchfab.com/3d-models/cute-cartoon-robot-1515bb8be733456e980fea34e37dec39)** (Sketchfab, лицензия CC BY — указать автора в README). Абзалу он нравится, хотя «чуть пацанский». Можно смягчить формы и цвета в Blender, но красный цвет героя — наш узнаваемый образ, оставь его.
- Заменить функцию `Hero()` в `src/game/Player.tsx`. **Физику не трогать:** капсула `RADIUS = 0.35`, `HALF_HEIGHT = 0.35`, герой высотой около 1.4 м. Модель вписать в эти размеры.
- Анимации: стоит / идёт / в прыжке / приземлился — по скорости и `grounded`. В `Player.tsx` уже есть сжатие при приземлении, покачивание и поворот к направлению. Сохрани это ощущение.
- Материал под новый свет: мягкий PBR и тёплый контровой свет по краю силуэта.

## 5. Жёсткие ограничения (нарушишь — сломаешь игру)

1. **Геометрия уровней — это данные.** `src/game/scenes/*/levelData.ts` задают платформы: `top` — высота поверхности, `w/d/h` — размеры. По ним строятся коллайдеры. Визуал может обрамлять платформы сколько угодно (скалы, корни, мох по бокам и снизу), **но верх платформы должен совпадать с `top`**, а края и пропасти должны оставаться **хорошо видны**: это платформер. Коллайдеры не меняй.
2. **«Загляни»:** стены двориков и их высоты проверяет тест `src/game/scenes/level2/level2.test.ts`. Видимость звезды считается лучами по коллайдерам. Стены можно одеть в камень, размеры и коллайдеры не трогай.
3. **«Поверни мир»:** доски моста-призрака (`Level3.tsx`, `GhostBridge`) собираются при повороте мира. Перекрашивай и улучшай, но механику не трогай.
4. **Эффект окна:** `src/game/WindowCamera.tsx` каждый кадр строит свою асимметричную матрицу проекции (`NEAR = 0.5`). Небо, лучи, туман и экранные эффекты проверяй **с движением головы**: стрелками в dev-режиме. Ничего не должно ломаться и дёргаться.
5. **Не трогай** (это зона Абзала): `src/input/*`, `src/shared/*`, `src/ui/*`, `src/game/voice*`, `src/game/holo/*`, `src/game/spirit/*` (только свет и цвет вокруг духа), `scripts/*`, `public/voice/*`. Если без правки там никак — сначала спроси Абзала.
6. **Производительность — критично.** Параллельно в браузере крутится распознавание MediaPipe (руки и лицо, на GPU). Цель — 60 к/с на среднем ноутбуке со встроенной видеокартой:
   - ориентир: до ~150 вызовов отрисовки и до ~300 тысяч треугольников в кадре;
   - текстуры до 1–2K;
   - GLB сжимать (gltf-transform: meshopt и webp), все ассеты в сумме до ~15 МБ;
   - уже есть `PerformanceMonitor` → флаг `runtime.lowQuality`; для слабых машин нужен заметно более дешёвый режим.
7. **Лицензии:** только CC0 / CC BY / свои. Всё использованное — в README, раздел «Что использовано», с авторами.

## 6. Как работать (обязательно)

1. **Сначала один кадр, потом всё остальное.** Собери **одну сцену-витрину**: остров лобби в сумерках, новый герой, дух, свет, дымка. Сделай скриншот и **покажи Абзалу**. Масштабировать на все уровни — только после его «да» на внешний вид. Прошлый раз целый прогон ушёл на визуал, который он не хотел: не повторяй.
2. **Раунды арт-директора.** Каждое изменение — скриншот и честная критика: композиция, цвет, читаемость платформ, пересвет, грязные тени, полосы на градиентах. Потом исправление. Минимум 3 раунда на каждую сцену.
3. **Проверяй в игре, а не только в превью:** dev-режим с клавиатурой, пройти уровень, попрыгать, подвигать «голову».
4. **Коммить маленькими шагами** в ветку `final-world`. В `main` и в деплой (`npm run deploy`) — только с разрешения Абзала.
5. Пиши комментарии в коде **по-русски, коротко**, как в остальном проекте (пример — `src/game/WindowCamera.tsx`).

## 7. Порядок работы

1. Модуль атмосферы (`t`, небо, солнце, свет, туман, лучи, цветокоррекция) + сцена-витрина лобби → **показать Абзалу**.
2. Герой (Sketchfab-робот) в витрине → **показать**.
3. Материалы и одежда островов: скалы, мох, корни, камень вместо toon-коробок; деревья и растения (модели из Quaternius Stylized Nature MegaKit, CC0, можно, но в новых материалах).
4. Все уровни и арка `t` по сценам; финал на рассвете.
5. Режим низкого качества, проверка производительности, README с авторами.

**Готово, когда:** каждая сцена выглядит как референс по настроению, платформы и пропасти легко читаются, дух светится, 60 к/с на среднем ноутбуке, typecheck, тесты и сборка зелёные, Абзал сказал «да».
